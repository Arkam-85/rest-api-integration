# REST API Integration

## Overview

This project demonstrates REST API concepts and practical API integration using React and the JSONPlaceholder public REST API.

## Features

- REST API GET request
- JSON response handling
- API data visualization
- Loading state
- Error handling
- Responsive design
- React state management

## API Used

JSONPlaceholder:

https://jsonplaceholder.typicode.com/

## Technologies

- React
- JavaScript
- CSS
- Vite
- Fetch API
- REST API

## Project Files

- `src/App.jsx` - React application and API integration
- `src/App.css` - Application styling
- `rest-api-report.md` - REST API research report
- `README.md` - Project documentation

## Conclusion

This project demonstrates how REST APIs can be integrated into React applications to retrieve, process and display JSON data.
